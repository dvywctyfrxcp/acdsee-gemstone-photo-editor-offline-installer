## About

ACDSee Gemstone Photo Editor is a Windows photo editing application combining layer-based editing with non-destructive RAW development. Features selection tools, healing brushes, text layers, blend modes, and a complete set of color correction tools. ACDSee Gemstone targets photography enthusiasts who want Photoshop-style layer editing at a lower price point within the ACDSee ecosystem.

## Common Problems & Limitations

- **Windows Only** — No macOS version as standalone editor
- **ACDSee Ecosystem** — Best value within full ACDSee subscription
- **Learning Curve** — Layer-based editing requires adjustment for RAW-first photographers
- **Community Size** — Smaller community and fewer tutorials than Photoshop or Affinity Photo
